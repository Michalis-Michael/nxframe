# 03_cpu_safe_development

Conservative presets for development machines and guaranteed realtime testing.

Use these for first bring-up, soak testing, and fallback validation. They reduce encoder complexity to protect realtime operation before picture-quality tuning.

For alpha.12, `x264_1080p50_pcm_cpu_safe` is the recommended first live 1080p50 validation preset.

Current presets in this folder are selected by short filename through the normal CLI preset resolver.
