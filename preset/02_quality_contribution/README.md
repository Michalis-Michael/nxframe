# 02_quality_contribution

Heavier quality-oriented presets for faster/future hardware.

Use these only after the CPU-safe and low-latency presets have passed long-duration tests. These presets may increase quality pressure through bitrate, references, motion search, trellis, or lookahead.

Do not use them as default appliance presets until realtime performance has been proven on the target hardware.

Current presets in this folder are selected by short filename through the normal CLI preset resolver.
